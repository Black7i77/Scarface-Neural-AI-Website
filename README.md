# Scarface Neural AI — Public Website

A **static landing page** for Scarface Neural AI, designed for GitHub Pages. It does **not** include the FastAPI backend, Ollama, accounts, or user data.

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `Scarface-Neural-AI-Website`.
2. Upload the contents of this folder to the repository root (not the ZIP itself).
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/(root)`, then Save.
6. The expected site address is `https://black7i77.github.io/Scarface-Neural-AI-Website/`.

## Preview locally
Open `index.html` in Firefox, or run `python3 -m http.server 8000` in this directory.

## Security
Never add `.env`, SQLite account databases, Ollama model files, API keys, authentication secrets, or agent workspaces to this repository. The public AI beta needs a separately secured backend and hosting environment.

This site contains no analytics, external dependencies, account collection, or fake AI demo. All feature labels accurately describe the **local prototype**.
